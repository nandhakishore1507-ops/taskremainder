# TaskFlow – Task Management System

## About the Project

TaskFlow is a dark-themed Task Management System developed using HTML, CSS, and JavaScript. It helps users organize their daily activities, manage tasks, track deadlines, and monitor their productivity through a simple and interactive dashboard.

The application allows users to create, edit, delete, search, and filter tasks. It also provides task priority levels, status tracking, overdue indicators, and a progress percentage.

## Objectives

- Develop a practical task management application.
- Apply HTML, CSS, and JavaScript concepts.
- Implement interactive user interface features.
- Manage task information using JavaScript.
- Store task data using browser Local Storage.
- Improve problem-solving and frontend development skills.

## Technologies Used

- HTML5 – Website structure.

## Features

1. Add new tasks with titles and descriptions.
2. Edit existing task details.
3. Delete unwanted tasks.
4. Set task priorities as Low, Medium, or High.
5. Assign due dates to tasks.
6. Track Pending, In Progress, and Completed tasks.
7. Search tasks using titles or descriptions.
8. Filter tasks based on their status.
9. Identify overdue tasks.
10. Display total task statistics.
11. Show overall task completion percentage.
12. Save tasks automatically using Local Storage.
13. Responsive dark-themed user interface.

## How to Run the Project

1. Download or clone the project.
2. Open the TaskFlow folder in Visual Studio Code.
3. Open the index.html file in a web browser.
4. Start adding and managing your tasks.

No additional installation is required.
